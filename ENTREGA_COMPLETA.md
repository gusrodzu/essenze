- Favicons y `site.webmanifest`.
- Nuevo grid navegable de colecciones.
- Corrección de la consulta GraphQL que provocaba el error 500.

## Instalación

1. Copia `.env.example` como `.env` y coloca tus variables reales.
2. Instala dependencias:

```bash
npm install
```

3. Inicia Hydrogen:

```bash
npm run dev
```

> Por seguridad, el archivo `.env`, `.git` y `node_modules` no están incluidos.
