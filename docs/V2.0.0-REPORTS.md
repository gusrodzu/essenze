# Changelog

## v2.0.0 — Reportes ejecutivos

- Centro de reportes para Compras, Inventario, Finanzas y Recursos Humanos.
- Filtros por rango de fechas.
- KPIs ejecutivos consolidados.
- Evolución mensual de compras, cuentas por cobrar y nómina.
- Principales proveedores por gasto.
- Clientes con mayor saldo pendiente.
- Capital humano por departamento.
- Alertas de vencimientos, solicitudes pendientes y stock crítico.
- Exportación del resumen a CSV.
- Permiso `reports.read`.
