# v5.6.2 — API import hotfix

Error corregido:

```text
SyntaxError: The requested module '../middleware/auth.js'
does not provide an export named 'requirePermission'
```

Import correcto:

```js
import {requireAuth} from '../middleware/auth.js';
import {requirePermission} from '../middleware/permissions.js';
```

Esta versión no cambia el schema Prisma. No requiere `db:generate` ni `db:sync`.
