# v5.7.1 — Aprobaciones integradas con Compras

## Regla operativa

Las órdenes de compra siguen creándose como `DRAFT`.

Si existe un workflow activo con `entityType = PURCHASE_ORDER` y al menos una regla aplicable al importe:

1. al crear la OC se genera automáticamente una `ApprovalRequest`;
2. la solicitud aparece en `/aprobaciones`;
3. la OC permanece en `DRAFT`;
4. `/purchase-orders/:id/issue` devuelve `409 APPROVAL_REQUIRED` mientras la aprobación esté pendiente;
5. si la solicitud es rechazada, la OC tampoco puede emitirse;
6. cuando la solicitud queda `APPROVED`, la misma acción de emitir OC funciona normalmente.

Si no existe workflow aplicable, se conserva el comportamiento histórico y la OC puede emitirse sin aprobación.

## Seguridad de datos

No se elimina ni resetea información existente.
