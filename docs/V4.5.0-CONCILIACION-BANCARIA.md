# Changelog

## v4.5.0 — Conciliación bancaria

- Estados de cuenta por cuenta bancaria y periodo.
- Captura manual de créditos y débitos bancarios.
- Comparación con movimientos de Tesorería.
- Relación uno a uno entre movimiento bancario y movimiento ERP.
- Validación de importes y cuentas.
- Movimientos ignorados con motivo documentado.
- Cálculo de saldo inicial, créditos, débitos y diferencia.
- Cierre bloqueado mientras existan movimientos pendientes o diferencias.
- Nueva ruta `Finanzas → Conciliación bancaria`.
- Nuevos modelos `BankStatement` y `BankStatementLine`.
