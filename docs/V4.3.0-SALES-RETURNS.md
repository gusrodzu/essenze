# Changelog

## v4.3.0 — Devoluciones y notas de crédito

- Devoluciones vinculadas a remisiones.
- Validación para no devolver más de lo entregado.
- Reingreso automático de existencias.
- Movimiento de Kardex por devolución.
- Notas de crédito vinculadas a facturas.
- Ajuste automático de cuentas por cobrar.
- Control de importes ya acreditados.
- Nueva ruta `Ventas → Devoluciones y notas de crédito`.
- Nuevos modelos `SalesReturn`, `SalesReturnItem` y `SalesCreditNote`.
- No incluye CFDI de egreso ni timbrado fiscal.


## Alcance fiscal

Las notas de crédito son documentos comerciales internos. El CFDI de egreso y su timbrado con PAC se integrarán posteriormente.
