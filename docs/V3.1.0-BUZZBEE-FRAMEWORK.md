# Changelog

## v3.1.0 — BuzzBee Framework

- Nuevo shell visual Business OS.
- Branding BuzzBee en la navegación.
- Command Palette global con Ctrl/Cmd + K.
- Búsqueda de Apps, pantallas y acciones rápidas.
- Centro visual Buzz AI.
- Tema claro y oscuro persistente.
- Topbar premium con IA, tema, notificaciones y perfil.
- Navegación organizada como Apps.
- Experiencia responsive para escritorio y móvil.
- No agrega nuevas tablas ni migraciones.
