# v5.5.2 — Seed demo hotfix

El seed de v5.5.1 se detenía en Producción con:

```text
ReferenceError: warehouseMain is not defined
```

La estructura demo ya crea los almacenes dentro del objeto `warehouses`, con el almacén
principal Monterrey bajo la clave `MTY-GEN`.

Se sustituyeron las referencias inválidas a:

```js
warehouseMain.id
```

por:

```js
warehouses['MTY-GEN'].id
```

en órdenes de Producción y terminal POS.

## Ejecución

No requiere `db:sync`.

```powershell
npm install
npm run db:seed
npm run db:seed:demo
npm run dev
```

El seed está diseñado para limpiar/recrear las transacciones demo, no requiere reset de la base.
