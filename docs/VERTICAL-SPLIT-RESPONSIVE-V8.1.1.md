# BuzzBee ERP v8.1.1 — Vertical Split Responsive

Optimiza el ERP cuando el navegador ocupa media pantalla o se usa en un monitor vertical.

## Comportamiento
- Hasta 1180 px el sidebar se convierte en drawer.
- El contenido recupera todo el ancho útil.
- BuzzBee AI rail se oculta y queda disponible por botón flotante.
- Topbar cambia a navegación compacta.
- Power Banner permanece visible sin invadir contenido.
- KPI pasan de 4 a 2 columnas y luego a 1.
- Headers, toolbars y grids complejos se apilan.
- Las tablas conservan scroll horizontal dentro de su card.
- Demo Ejecutiva reorganiza los 8 pasos en 2 columnas / 1 columna.
- Demo Company apila sus paneles.

## Uso objetivo
- Windows Snap 50/50.
- Monitor vertical.
- Ventanas de aproximadamente 700–1180 px de ancho.
- Tablet landscape / narrow desktop.

No cambia Prisma ni datos.
