# v4.8.0 — Datos reales y validación de integración

Base: **v4.7.5 corregida y estable**.

## Implementado

- Dashboard conectado a PostgreSQL mediante `GET /api/dashboard`.
- KPIs reales:
  - solicitudes pendientes
  - órdenes del mes
  - variación mensual de compras
  - valor de inventario
  - stock crítico
- Solicitudes recientes desde la BD.
- Compras mensuales de los últimos 12 meses.
- Alertas de inventario reales.
- Distribución del valor de inventario por categoría.
- Agenda financiera usando CxC y CxP próximas a vencer.
- Actividad de usuarios basada en `lastLoginAt`.
- Resumen operativo desde notificaciones.
- Acciones rápidas con navegación real.
- Script `npm run validate:data` para detectar pantallas funcionales sin consumo de API.
- El API en desarrollo usa `node src/index.js` para mantener la estabilidad observada en el entorno actual.

## Datos demo

El archivo `apps/api/prisma/seed-demo.js` se conserva. Ejecutarlo es opcional:

```powershell
npm run db:seed:demo
```

No es necesario para que el sistema funcione si ya tienes datos en PostgreSQL.

## Instalación

```powershell
npm install
npm run db:generate
npm run validate:data
npm run dev
```

No ejecutar `prisma migrate reset` ni `docker compose down -v`.
