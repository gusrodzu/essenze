# ERP Cliente v5.0.0 — Proyectos

Base estable: v4.9.0 CRM.

## Alcance

El nuevo módulo `/proyectos` incorpora:

- Portafolio de proyectos.
- Proyectos y subproyectos.
- Cliente y responsable.
- Estados y prioridades.
- Presupuesto y horas planeadas.
- Tablero de tareas.
- Responsables y fechas límite.
- Avance automático basado en tareas.
- Equipo del proyecto y porcentaje de asignación.
- Registro de horas y costo por hora.
- Costo real de mano de obra.
- Vinculación con pedidos de venta.
- Vinculación con órdenes de compra.
- Presupuesto vs costo real.
- Ingresos vinculados y margen.
- Comentarios / bitácora.
- Archivos adjuntos.
- KPIs de portafolio.
- Datos demo.
- Permisos `projects.read` y `projects.manage`.
- Auditoría de acciones.

## Flujo integrado

Cliente → Venta → Proyecto → Tareas → Equipo → Horas → Compras → Costos → Margen

## Actualización segura desde v4.9.0

Esta versión agrega nuevas tablas, enums y relaciones de Prisma. Los cambios son aditivos.

No usar:

```powershell
prisma migrate reset
docker compose down -v
```

No es necesario borrar el volumen de PostgreSQL.

### Primera ejecución de v5.0.0

```powershell
docker start erp-cliente-postgres
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

`npm run db:seed` registra los permisos nuevos del módulo y los asigna al rol Administrador.
`npm run db:seed:demo` agrega proyectos de demostración.

### Arranques posteriores

```powershell
docker start erp-cliente-postgres
npm run dev
```

No vuelvas a ejecutar `db:sync` ni los seeds en cada arranque.
