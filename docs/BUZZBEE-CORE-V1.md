# BuzzBee Core v1 — Master Data

Principios oficiales: Modular by default, Single Source of Truth, API First, Workflow Driven, Data Quality First, Progressive Complexity e Intelligence Everywhere.

Master Data v1 mantiene Customer, Supplier, Product y Employee como fuentes transaccionales para evitar una migración destructiva y agrega contactos/direcciones maestras, catálogos y DataQualityIssue. El scanner detecta posibles duplicados, datos incompletos y formatos inválidos; no elimina ni fusiona registros automáticamente.
