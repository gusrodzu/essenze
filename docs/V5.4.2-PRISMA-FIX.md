# v5.4.2 — Prisma relation fix

Corrige específicamente la relación inversa de:

```prisma
model ProductionOrder {
  product Product @relation(fields: [productId], references: [id], onDelete: Restrict)
}
```

agregando DENTRO de `model Product`:

```prisma
productionOrders ProductionOrder[]
```

Este hotfix sustituye v5.4.1.

## Orden de ejecución

```powershell
npm install
npm run db:generate
```

Solo si `db:generate` termina correctamente:

```powershell
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

No usar `prisma migrate reset` ni borrar volúmenes.
