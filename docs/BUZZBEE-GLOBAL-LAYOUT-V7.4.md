# BuzzBee v7.4.0 — Global Modules Layout

BuzzBee AI, Aplicaciones y Explora todo el poder de BuzzBee forman parte del layout normal de AppShell.

- BuzzBee AI y Aplicaciones permanecen en el rail derecho en desktop.
- El banner se renderiza al final del contenido como footer global.
- El banner ya no usa `position: fixed` y no se superpone a tablas, formularios ni botones.
- Se ajustaron dimensiones del rail derecho para acercarlo a la referencia visual.
- En tablet/móvil el rail se oculta y BuzzBee AI sigue accesible mediante el botón flotante; el banner permanece al final de cada ruta.
- Sin cambios de base de datos.
