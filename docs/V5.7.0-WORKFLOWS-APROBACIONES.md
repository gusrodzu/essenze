# v5.7.0 — Workflows y Aprobaciones

Este módulo centraliza autorizaciones antes de ejecutar procesos sensibles.

## Dominio
- ApprovalWorkflow
- ApprovalRule
- ApprovalRequest
- ApprovalStep
- ApprovalAction

## Alcance actual
El motor es genérico: cada solicitud guarda `entityType` y `entityId`, por lo que puede conectarse después a:
- órdenes de compra;
- pagos;
- vacaciones;
- descuentos;
- producción;
- gastos;
- transferencias;
- notas de crédito.

La versión 5.7.0 no bloquea automáticamente esos procesos todavía. Esa integración debe hacerse módulo por módulo para no romper flujos existentes.

## Actualización segura
```powershell
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

Si `db:sync` muestra advertencia de pérdida de datos, cancelar.
No usar `prisma migrate reset`.
