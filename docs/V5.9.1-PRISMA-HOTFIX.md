# v5.9.1 — Prisma schema hotfix

Corrige una línea inválida heredada en `Role`:

```prisma
permissions   RolePermission[]
approvalRules ApprovalRule[]
approvalSteps ApprovalStep[]
```

También mueve el mensaje de éxito de `seed-demo.js` al final real del proceso.

No borra datos ni requiere reset.
Después de instalar:
1. npm install
2. npm run db:generate
3. npm run db:sync
4. npm run db:seed:demo

Si `db:sync` advierte data loss, cancelar.
