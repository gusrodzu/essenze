# v5.9.0 — Gastos y Viáticos

Incluye:
- categorías de gasto;
- registro de gastos/viáticos;
- método de pago;
- comprobante por URL y folio;
- reembolsable/no reembolsable;
- flujo DRAFT → SUBMITTED → APPROVED/REJECTED → PAID;
- integración con ApprovalWorkflow usando entityType `EXPENSE`;
- dashboard financiero y saldo por reembolsar.

Esta versión agrega tablas Prisma. Sincronizar con `npm run db:generate` y `npm run db:sync`.
Si Prisma advierte pérdida de datos, cancelar.
