# Changelog

## v2.2.0 — Tesorería

- Cajas y cuentas bancarias.
- Saldo inicial y saldo disponible.
- Ingresos, egresos y ajustes.
- Transferencias entre cuentas.
- Validación de saldo disponible.
- Bitácora de movimientos con saldo posterior.
- Indicadores de efectivo, bancos y saldo total.
- Permisos `treasury.read`, `treasury.manage` y `treasury.move`.
