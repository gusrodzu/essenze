# v4.9.0 — CRM

Base: **v4.8.1 estable**.

## Nuevo módulo CRM

Ruta: `/crm`

Incluye:

- Resumen comercial con KPIs.
- Pipeline Kanban por etapas:
  - Lead
  - Contactado
  - Calificado
  - Propuesta
  - Ganado
  - Perdido
- Leads y oportunidades.
- Valor estimado y probabilidad de cierre.
- Fuente del lead.
- Próximo seguimiento.
- Agenda de actividades:
  - notas
  - llamadas
  - correos
  - reuniones
  - tareas
- Completar y reabrir actividades.
- Conversión **Prospecto → Cliente**.
- La conversión crea el cliente en el catálogo real de Finanzas/Ventas.
- Auditoría de conversiones y actividades.
- Integración con los datos demo ya existentes.

## Importante

Esta versión **no agrega tablas ni columnas nuevas a Prisma**. Reutiliza `Prospect`,
`SalesActivity` y `Customer`, que ya forman parte de la base estable.

Por lo tanto:

- No necesita `prisma migrate reset`.
- No necesita volver a cargar los datos demo.
- No necesita borrar el volumen de PostgreSQL.

Para usarla:

```powershell
npm install
npm run db:generate
npm run dev
```

Después abre el módulo **CRM** desde el menú principal.
