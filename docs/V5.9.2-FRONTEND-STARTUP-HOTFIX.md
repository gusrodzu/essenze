# v5.9.2 — Frontend Startup Hotfix

Corrige el bloqueo en la pantalla estática **“Iniciando BuzzBee…”**.

## Causa
`apps/web/src/data/navigation.js` usaba:

```js
icon: Receipt
```

para **Gastos y viáticos**, pero `Receipt` no estaba importado desde `lucide-react`.
Eso produce un `ReferenceError` al evaluar el módulo de navegación y React nunca llega a montarse.

## Corrección
Se agregó `Receipt` al import de `lucide-react`.

No modifica Prisma, PostgreSQL ni datos.
