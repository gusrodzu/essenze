# ERP Cliente v1.6.0 — Recursos Humanos

Incluye empleados, departamentos, puestos, sucursal, sueldo, fechas y estatus laboral.

## Permisos
- `employees.read`
- `employees.manage`

## Ruta
- `/recursos-humanos`

## API
- `GET /api/human-resources`
- `POST /api/human-resources/employees`
- `PUT /api/human-resources/employees/:id`
- `PATCH /api/human-resources/employees/:id/status`
- CRUD base de departamentos y puestos.
