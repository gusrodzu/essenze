# ERP Cliente v5.4.0 — POS

## Nuevo módulo `/pos`

Incluye:

- Terminales POS.
- Terminal vinculada a almacén.
- Apertura/cierre de sesión de caja.
- Fondo inicial.
- Conteo y diferencia al cierre.
- Movimientos de efectivo.
- Tickets de venta.
- Clientes opcionales.
- Líneas de ticket.
- Descuentos.
- Impuestos.
- Pagos múltiples.
- Efectivo, tarjeta, transferencia, wallet, crédito y otros.
- Historial de tickets.
- Anulación de ventas.
- KPIs del día.
- Datos demo.

## Flujo

Terminal → Apertura de caja → Ticket → Productos → Cliente → Pagos →
Venta → Caja → Cierre

## Primera ejecución desde v5.3.0

```powershell
docker start erp-cliente-postgres
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

Cambios Prisma aditivos. No usar `prisma migrate reset` ni `docker compose down -v`.
