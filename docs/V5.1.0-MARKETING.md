# ERP Cliente v5.1.0 — Marketing

Base: v5.0.0 Proyectos.

## Módulo

Ruta: `/marketing`

### Capacidades
- Dashboard de Marketing.
- Campañas, estados, objetivos, responsables y canales.
- Presupuesto e inversión real.
- Gastos por campaña.
- Métricas: impresiones, clicks, sesiones, leads, conversiones, spend y revenue.
- KPIs: CPL, CTR, tasa de conversión, ROAS y ROI.
- Leads vinculados al CRM.
- Atribución de oportunidades y pedidos de venta.
- Revenue atribuido y porcentaje de atribución.
- Calendario editorial/operativo.
- Eventos y milestones.
- Tracking UTM.
- Datos demo.
- Auditoría.
- Permisos `marketing.read` y `marketing.manage`.

## Flujo integrado

Marketing → Lead → CRM → Oportunidad → Cliente → Pedido → Revenue → ROI

## Primera ejecución al actualizar desde v5.0.0

```powershell
docker start erp-cliente-postgres
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

La actualización Prisma es aditiva. No uses `prisma migrate reset` ni `docker compose down -v`.
