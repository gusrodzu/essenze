# Changelog

## v4.1.0 — Sales App Enterprise

- Dashboard comercial con ventas, cotizaciones, pedidos, cobranza y clientes.
- Pipeline Kanban de prospectos.
- Alta y edición de prospectos.
- Etapas, probabilidad, valor estimado y próxima acción.
- Timeline de actividad comercial.
- Resumen de cotizaciones recientes.
- Resumen de cuentas por cobrar.
- Integración con la pantalla existente de cotizaciones y pedidos.
- Nuevos modelos `Prospect` y `SalesActivity`.
- Nueva ruta API `/api/sales-enterprise`.
- Conserva Foundation, tema, navegación y Error Boundary de v4.0.0.


## Alcance de esta versión

Incluye el centro comercial, pipeline, cotizaciones, pedidos y visibilidad de cobranza.

Las remisiones con afectación de inventario y la generación/timbrado de CFDI se implementarán en una versión posterior para mantener separadas la operación logística y la integración fiscal.
