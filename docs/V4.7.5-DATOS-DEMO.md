## Carga recomendada

```powershell
docker compose up -d
npm install
npm run db:generate
npm run db:migrate
npm run db:reset:demo
npm run dev
```

`db:reset:demo` ejecuta primero el seed mínimo y después carga la información
demostrativa. No elimina los datos maestros existentes; reemplaza únicamente
las transacciones identificadas con folios demo.
