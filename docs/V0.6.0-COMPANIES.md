# v0.6.0 — Empresas y configuración organizacional

## Objetivo

Convertir la entidad Company en un módulo administrable y preparar el ERP para sucursales, almacenes y operaciones segmentadas.

## API

- `GET /api/company`
- `PUT /api/company`
- `POST /api/company/branches`
- `PUT /api/company/branches/:id`
- `DELETE /api/company/branches/:id`

Todos los endpoints requieren JWT y limitan las operaciones a la empresa del usuario autenticado.
