# ERP Cliente v5.2.0 — Facturación fiscal / CFDI

Base: v5.1.0 Marketing.

## Alcance

- Perfil fiscal del emisor.
- Perfil fiscal de clientes/receptores.
- Preparación de CFDI 4.0 desde facturas comerciales.
- Conceptos fiscales e impuestos.
- Campos de receptor requeridos: razón social, régimen y código postal.
- Exportación, ObjetoImp, Uso CFDI, método y forma de pago.
- Registro seguro del resultado de timbrado de un PAC.
- UUID, fecha de timbrado, XML/PDF y estado SAT.
- Solicitudes/resultados de cancelación.
- Complemento de recepción de pagos 2.0.
- Relación del complemento con cobros y CFDI timbrados.
- KPIs fiscales.
- Datos demo.
- Permisos `fiscal.read` y `fiscal.manage`.

## Importante

v5.2.0 NO falsifica ni simula un timbrado. Administra el documento y permite guardar
el resultado que entregue un PAC real. La integración HTTP con un PAC específico puede
hacerse en una versión posterior sin cambiar el dominio fiscal.

## Actualización

```powershell
docker start erp-cliente-postgres
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

Cambios Prisma aditivos. No usar `prisma migrate reset` ni `docker compose down -v`.
