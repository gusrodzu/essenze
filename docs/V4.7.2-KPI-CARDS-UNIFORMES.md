# Changelog

## v4.7.2 — KPI Cards uniformes

- Estandarización global de altura, padding, radio, sombra y jerarquía tipográfica.
- Tamaño consistente para iconos, títulos, valores y descripciones.
- Espacio reservado para el botón de información.
- Popover renderizado mediante React Portal directamente sobre `document.body`.
- Nivel visual superior a cards, tablas, contenedores, sidebars y elementos con overflow.
- Posicionamiento automático arriba o abajo según el espacio disponible.
- Reposicionamiento al hacer scroll o cambiar el tamaño de la ventana.
- Cierre al hacer clic fuera o presionar Escape.
- Presentación móvil fija en la parte inferior.
- No requiere migración de Prisma.
