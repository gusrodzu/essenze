# v1.2.0 — Recepciones e inventario

Esta versión cierra el ciclo operativo de compras:

1. La orden de compra se emite.
2. El almacén registra una recepción parcial o total.
3. Se crea un documento de recepción con folio `REC-AAAA-0000`.
4. Se actualiza la cantidad recibida de cada partida.
5. Se incrementa la existencia por producto y almacén.
6. Se recalcula el costo promedio ponderado.
7. Se genera un movimiento de Kardex.
8. La orden cambia a recepción parcial o recibida.

## Modelos nuevos

- `GoodsReceipt`
- `GoodsReceiptItem`
- `InventoryBalance`
- `InventoryMovement`

## Rutas nuevas

- `GET /api/receipts`
- `POST /api/receipts`
- `GET /api/inventory/balances`
- `GET /api/inventory/movements`
