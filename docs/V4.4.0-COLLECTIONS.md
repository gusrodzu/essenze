# Changelog

## v4.4.0 — Cobranza y aplicación de pagos

- Registro de cobros de clientes.
- Métodos: transferencia, efectivo, tarjeta, cheque y otros.
- Depósito automático en Tesorería.
- Aplicación total o parcial a facturas.
- Pagos con saldo no aplicado.
- Actualización automática de cuentas por cobrar.
- Actualización del estado de la factura comercial.
- Nueva ruta `Ventas → Cobranza`.
- Nuevos modelos `CollectionReceipt` y `CollectionApplication`.
- Mantiene compatibilidad con el modelo histórico `CustomerPayment`.
