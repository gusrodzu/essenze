# v5.4.1 — POS Hotfix

## Problema corregido

Prisma P1012:

`ProductionOrder.product` tenía:

```prisma
product Product @relation(fields: [productId], references: [id], onDelete: Restrict)
```

pero `Product` no tenía la relación inversa.

Se agregó:

```prisma
productionOrders ProductionOrder[]
```

El error:

`Cannot read properties of undefined (reading 'deleteMany')`

en `prisma.posDiscount.deleteMany()` era una consecuencia: `prisma generate`
había fallado y `@prisma/client` seguía usando una versión anterior, sin los modelos POS.

## Orden seguro de actualización

```powershell
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

No ejecutar `prisma migrate reset` ni `docker compose down -v`.

Si `npm run db:sync` muestra una advertencia de pérdida de datos, detenerse y revisar el mensaje.
