# v1.0.0 — Solicitudes de compra

Primer flujo operativo completo del ERP.

## Flujo

1. El usuario crea una solicitud en borrador.
2. Agrega productos, cantidades y costos estimados.
3. Envía la solicitud a aprobación.
4. Un usuario autorizado aprueba o rechaza.
5. Una solicitud aprobada queda preparada para convertirse en orden de compra en la siguiente versión.

## Estados

- DRAFT
- PENDING
- APPROVED
- REJECTED
- ORDERED
- CANCELLED
