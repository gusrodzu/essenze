# v5.5.1 — Navegación modular

## Correcciones

1. `Módulos y planes` ahora aparece en el menú **Sistema**.
2. El Sidebar consulta `/api/modules/dashboard`.
3. Los módulos desactivados mediante Configuración modular dejan de mostrarse en el menú de la empresa.
4. Si un usuario no tiene permiso `modules.read`, el sistema conserva el menú completo como fallback para no bloquear usuarios existentes.
5. No hay cambios Prisma en esta versión.

## Instalación

No requiere `db:sync`.

```powershell
npm install
npm run dev
```

Si vienes directamente de una versión anterior a v5.5.0, entonces sí debes aplicar primero los cambios de base de v5.5.0.
