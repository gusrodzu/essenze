# Changelog

## v2.2.2 — Corrección definitiva de KPIs

- Se corrige el selector visual para el componente `Card`.
- `Card` renderiza un elemento `<section>`, no `<article>`.
- Ahora se usa `.metrics > *`, compatible con todos los componentes KPI.
- Concepto y valor quedan siempre en líneas separadas.
- No requiere migración de base de datos.
