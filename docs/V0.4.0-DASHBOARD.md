# v0.4.0 — Dashboard Experience

Esta versión mejora la experiencia de inicio del ERP sin modificar la infraestructura estable.

## Incluye

- Dashboard ejecutivo responsive.
- KPIs de compras, órdenes, inventario y stock crítico.
- Resumen inteligente visual.
- Gráfica de compras mensuales sin dependencias adicionales.
- Solicitudes recientes.
- Alertas de inventario.
- Agenda operativa.
- Distribución de gasto por área.
- Equipo conectado.
- Personalización de widgets.
- Vista compacta.
- Preferencias persistentes en `localStorage`.

## No incluye

- Autenticación.
- Datos reales de módulos.
- Drag and drop físico de widgets.
- Persistencia de preferencias en base de datos.
