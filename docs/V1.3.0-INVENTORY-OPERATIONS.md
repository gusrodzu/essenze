# v1.3.0 — Operaciones de inventario

Esta versión agrega transferencias entre almacenes y ajustes de inventario.

## Funciones

- Transferencias con salida y entrada automática en Kardex.
- Validación de existencia disponible en almacén origen.
- Ajustes de entrada y salida con motivo obligatorio.
- Actualización de existencias y costo promedio.
- Folios automáticos `TRF-AAAA-0000` y `AJU-AAAA-0000`.
- Auditoría de operaciones.

## Permisos

- `inventory_transfers.manage`
- `inventory_adjustments.manage`
