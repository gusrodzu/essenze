# v5.6.1 — Billing hotfix

La v5.6.0 tenía dos regresiones:

1. `SubscriptionPlan.scheduledSubscriptions` declaraba la relación inversa, pero
   `CompanySubscription` no tenía `scheduledPlan`.
2. `Billing.jsx` estaba importado, pero faltaba su `<Route>` en `App.jsx`.

## Instalación segura

```powershell
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

Si `db:sync` advierte pérdida de datos, cancelar y revisar el mensaje.
No usar `prisma migrate reset`.
