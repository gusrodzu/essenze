# Changelog

## v4.2.0 — Remisiones y facturación comercial

- Remisiones vinculadas a pedidos confirmados.
- Entregas parciales y completas.
- Salida automática de inventario.
- Movimiento de Kardex por remisión.
- Actualización de cantidades entregadas.
- Factura comercial vinculada a pedido.
- Creación automática de cuenta por cobrar.
- Nueva ruta `Ventas → Entregas y facturación`.
- Nuevos modelos `SalesDelivery`, `SalesDeliveryItem` y `SalesInvoice`.
- No incluye timbrado CFDI.


## Alcance fiscal

La factura generada es un documento comercial interno. El timbrado CFDI, PAC, XML y cancelaciones fiscales se integrarán en una versión posterior.
