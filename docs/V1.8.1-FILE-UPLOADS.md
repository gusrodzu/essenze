# v1.8.1 — Carga de archivos en expedientes

- Campo de carga directa en Expedientes laborales.
- Formatos permitidos: PDF, JPG, PNG, WEBP, DOC y DOCX.
- Tamaño máximo: 10 MB.
- Archivos almacenados localmente en `apps/api/uploads` para desarrollo.
- Endpoint protegido: `POST /api/employee-documents/upload`.
- La URL externa se conserva como alternativa.
- Preparado para reemplazar almacenamiento local por Google Cloud Storage en producción.
