# BuzzBee v7.4.2 — Full Height Right Rail

BuzzBee AI y Aplicaciones ahora ocupan todo el alto disponible de la sección
entre Topbar y el banner inferior.

- BuzzBee AI: bloque superior flexible.
- Aplicaciones: bloque inferior flexible.
- Ambos permanecen visibles.
- El contenido central sigue siendo el único que hace scroll.
- El banner inferior sigue siempre visible.
- Si el contenido interno excede el alto disponible, el scroll ocurre dentro
  de prompts o aplicaciones, no en el shell completo.

Sin cambios de base de datos.
