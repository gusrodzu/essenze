# BuzzBee Business OS UI — v7.1.0

Esta versión inicia la migración visual oficial hacia la interfaz Business OS.

## Principio
La complejidad técnica vive en el Core; el usuario ve lenguaje de negocio.

Ejemplos:
- BuzzBee Flow → Automatizaciones
- Integration Hub → Integraciones
- Business Party → Clientes / Proveedores
- Intelligence → Reportes / Analytics & Forecast / BuzzBee AI
- Data Hub / Master Data → Datos y calidad / Importar datos

## Navegación
- Principal
- Operación
- Relaciones
- Administración
- Inteligencia
- Sistema
- Configuración

## Cambios
- Sidebar oscuro oficial.
- Inicio orientado a prioridades.
- Menú técnico simplificado.
- Quick Actions corregidas para usar la propiedad `to`.
- Se conservan rutas y módulos existentes.
- No hay migración destructiva de datos.
- Se mantiene el KPI Design System compartido.
