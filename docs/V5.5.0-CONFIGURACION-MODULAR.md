# ERP Cliente v5.5.0 — Configuración modular SaaS

Nuevo módulo: `/configuracion/modulos`

Incluye:
- Catálogo global de módulos.
- Activación/desactivación de módulos por empresa.
- Features por módulo.
- Planes de suscripción.
- Módulos incluidos por plan.
- Features por plan.
- Límites por plan.
- Overrides de límites por empresa.
- Suscripciones por empresa.
- Estados trial/active/past due/suspended/cancelled/expired.
- Usage records por periodo.
- Preparación para billing externo.

Flujo:
Plan → Suscripción → CompanyModule → Feature flags → Límites → Uso

Primera ejecución:
```powershell
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

Si `db:generate` falla, no ejecutar `db:sync`.
Si `db:sync` advierte pérdida de datos, detenerse.
