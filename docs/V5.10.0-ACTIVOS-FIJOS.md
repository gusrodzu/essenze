# v5.10.0 — Activos Fijos

Incluye:
- catálogo de categorías patrimoniales;
- alta de activos;
- marca, modelo, serie, ubicación y custodio;
- costo de adquisición, residual y vida útil;
- depreciación lineal;
- valor en libros;
- actualización de depreciación acumulada;
- baja, venta o pérdida;
- KPIs patrimoniales.

Agrega modelos Prisma `FixedAssetCategory` y `FixedAsset`.

Instalación:
1. npm install
2. npm run db:generate
3. npm run db:sync
4. npm run db:seed
5. npm run db:seed:demo

Si `db:sync` advierte pérdida de datos, cancelar.
