# ERP Cliente v5.3.0 — Producción / Manufactura

## Nuevo módulo `/produccion`

Incluye:

- Centros de trabajo.
- Listas de materiales (BOM).
- Versiones de BOM.
- Ordenes de producción.
- Integración con pedidos de venta y proyectos.
- Almacén de materiales y almacén de producto terminado.
- Explosión de materiales desde la BOM.
- Operaciones / routing.
- Responsables y centros de trabajo por operación.
- Tiempos planeados y reales.
- Consumos reales de materiales.
- Producción terminada.
- Lotes.
- Mermas y rechazo.
- Costos de material, mano de obra, overhead y externos.
- Costo total y costo unitario.
- KPIs de producción.
- Datos demo.

## Flujo

Venta / Proyecto → Orden de Producción → BOM → Materiales → Operaciones →
Producto terminado → Lote → Costeo

## Instalación desde v5.2.0

```powershell
docker start erp-cliente-postgres
npm install
npm run db:generate
npm run db:sync
npm run db:seed
npm run db:seed:demo
npm run dev
```

Cambios de Prisma aditivos. No usar `prisma migrate reset` ni `docker compose down -v`.
