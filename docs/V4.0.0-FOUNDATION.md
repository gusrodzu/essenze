# Changelog

## v4.0.0 — Foundation

- Corrige definitivamente `ThemeProvider is not defined`.
- Centraliza React Query y ThemeProvider en `AppProviders`.
- Agrega `AppErrorBoundary` para evitar pantallas blancas silenciosas.
- Agrega pantalla de carga inicial en `index.html`.
- ThemeContext defensivo ante localStorage bloqueado.
- Validación automática con `npm run validate:foundation`.
- Conserva todos los módulos, rutas, APIs y modelos de v3.1.0.
- No requiere una migración nueva de Prisma.


## Arquitectura de inicio

```text
main.jsx
└── AppErrorBoundary
    └── AppProviders
        ├── ThemeProvider
        └── QueryClientProvider
            └── App
```
