# Essenze — White Luxury Migration

La interfaz principal fue actualizada de marfil a blanco puro.

## Cambios visuales

- Fondo general: `#ffffff`.
- Superficies secundarias: `#f7f7f7`.
- Tarjetas: blanco con bordes grises muy ligeros.
- Sombras: neutrales, sin matiz café.
- Se conserva el dorado como acento de lujo.
- Se conserva el negro para tipografía, CTAs y secciones de contraste.
- La página de producto y el dossier de metacampos usan fondos blancos.

## Archivos principales

- `app/styles/essenze-design-system.css`
- `app/components/product.module.css`
- `app/components/ProductMetafields.module.css`
- Resto de archivos CSS con fondos cálidos neutralizados.

No se incluyeron credenciales ni archivo `.env`.
