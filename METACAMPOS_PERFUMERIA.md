# Metacampos de perfumería — Essenze

Crea estas definiciones en Shopify Admin → Configuración → Datos personalizados → Productos.
Namespace recomendado: `custom`.

| Nombre | Key | Tipo recomendado |
|---|---|---|
| Concentración | `concentracion` | Texto de una línea |
| Duración | `duracion` | Texto de una línea (ej. `8 horas` o `4/5`) |
| Estela | `estela` | Texto de una línea (ej. `Intensa` o `4/5`) |
| Intensidad | `intensidad` | Texto de una línea (1–5 o descripción) |
| Año de lanzamiento | `ano_de_lanzamiento` | Número entero |
| Perfumista | `perfumista` | Texto de una línea |
| Notas de salida | `notas_de_salida` | Lista de textos o texto multilínea |
| Notas de corazón | `notas_de_corazon` | Lista de textos o texto multilínea |
| Notas de fondo | `notas_base` | Lista de textos o texto multilínea |
| Familia olfativa | `familia_olfativa` | Lista de textos / opción predefinida |

## Familias aromáticas generales

- Cítrica
- Acuática
- Aromática
- Frutal
- Floral
- Chipre
- Amaderada
- Ámbar
- Gourmand
- Cuero

Los medidores de Intensidad, Duración y Estela aceptan valores como `1/5`, `4`, `Suave`, `Moderada`, `Intensa`, `Muy intensa` o duración en horas. La escala visual usa rojo → naranja → amarillo → verde.
