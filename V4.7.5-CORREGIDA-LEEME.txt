INSTALACIÓN SEGURA

1. Descomprime en una carpeta nueva.
2. Copia tus .env actuales (especialmente apps/api/.env, si ahí lo manejas).
3. NO borres tu volumen de Docker.
4. NO ejecutes prisma migrate reset.
5. Instala dependencias:

   npm install

6. Genera Prisma Client:

   npm run db:generate

7. Inicia primero la API:

   npm run dev:api

8. Si la API queda activa, inicia el proyecto:

   npm run dev

DATOS DEMO
Solo cuando la API y tu BD estén correctas:

   npm run db:seed:demo

El seed demo es opcional y no es necesario para iniciar sesión.
